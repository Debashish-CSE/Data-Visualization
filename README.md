# Data Visualization Projects

Welcome to **Data Visualization Projects** — a curated collection of my work on data visualization, including reports, scripts, and coursework completed during my academic journey. This repository is organized by technology and language, focusing on LaTeX and R.

You'll find folders for LaTeX sources and R scripts, each containing relevant files for visualizing, analyzing, and presenting data.

---

### Folder Descriptions

- **LaTeX**  
  This folder contains data visualization tasks and academic documentation using LaTeX, with a strong focus on packages such as **TikZ** and **PGFPlots** for creating high-quality charts and graphs (bar charts, scatter plots, line charts, histograms, etc.).  
  You will also find PDF reports, Beamer presentations, and PowerPoint slides that explain key concepts like when to use different types of charts (bar vs. pie vs. scatter), and how to present data clearly in academic or professional contexts.

- **R_data_visualization**  
  This folder features data visualization projects using R, especially the **ggplot2** library.  
  Included are scripts and notes for generating a variety of chart types (bar charts, column charts, pie charts, scatter plots, line graphs, box plots, and more).  
  The folder also covers data manipulation tasks in R, such as reading and cleaning data from CSV files, preparing datasets for visualization, and choosing the most effective chart type for a given data structure or analysis task.

## 🚀 How to Use

Each folder is **self-contained**—navigate directly to the folder of interest to find source code, scripts, or reports.

### Example: Compiling LaTeX

```sh
cd LaTeX
pdflatex report.tex
```

### Example: Running R Scripts

```sh
cd R_data_visualization
Rscript analysis.R
```

> **Note:** Some files may require specific compilers or libraries. Please check for any `README` or instructions inside individual folders.
